## K5 journey run

From the archived product with the named harness overlay:

```sh
CARGO_INCREMENTAL=0 \
CARGO_TARGET_DIR=/home/nade/workspaces/personal/crew/.crew/worktrees/native-transport/target/native-validation/k5-e7/target \
CREW_NATIVE_VALIDATION_BIN=/home/nade/workspaces/personal/crew/.crew/worktrees/qa/target/native-validation/gateway-integration/bin/crew \
  bash scripts/build-env cargo test --locked -p crew-client-transport \
  --features journey-tests --test gateway_daemon journey:: -- --nocapture
```

Both journeys passed (2/2, 1.62 s). Compilation/linking took 14.09 s using an
owned scoped target with incremental compilation disabled. Available storage
remained approximately 166 GiB, above the 100 GiB resource floor. The heavy
Cargo slot was released immediately afterward.

The local journey proves protected discovery and canonical binding, one-socket
snapshot/push behavior through the real engine, task/current-work projections,
question answer and stale-answer refusal, sending, two independently identified
attachments, resize/input transport completions, local detach, a confirmed
kill followed by actual PTY end, and a newer reconnect scope rejecting old
intents. It failed before the PTY correction because the retained broadcast
sender kept the killed attachment open; the unchanged fixture now passes.

The scoped journey proves Read default and separate Control/Terminal grants,
TaskCard reads/current-work projections, unauthorized-workspace refusal,
answer/send refusal under Read, a grant change requiring a new scope, actual
answer/send under Control, canceled confirmation refusing execution, Terminal
refusal under Control alone, two real PTY attachments with resize/input, and
workspace revocation ending both attachments with their captured full scopes
and IDs. Identified success notices precede all real terminal bytes.

Fixtures re-execute with all inherited `GIT_*`, `HERDR_*` and `CREW_*` context
removed except the explicitly supplied test binary. Runtime/state/config and
workspace directories are temporary. Only ephemeral loopback TLS listeners and
synthetic public test keys are used. Cleanup stops only the fixture team.
