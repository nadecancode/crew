Reproduce

Install dependencies with cd web && bun install --frozen-lockfile. From repository root, set PLAYWRIGHT_EXECUTABLE_PATH to a Chromium executable and run node notes/web-revamp/capture-baseline.mjs, node notes/web-revamp/capture-mockups.mjs, then node notes/web-revamp/build-gallery.mjs.

The baseline script starts and stops its own mock. No real workspaces are contacted. The mockup script captures local files. Baseline measurements · Reference manifest
